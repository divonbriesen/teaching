WEB250 • Database Driven Websites

Catalog description

This course introduces dynamic (database-driven) website development. Topics include the use of basic database CRUD statements (create, read, update and delete) incorporated into web applications, as well as in software architecture principles.

Official description from the Combined Course Library of the North Carolina Community College System. 3 credit hours, 2 class hours and 3 lab hours.

Where the site stops being files and starts being data

You arrive able to build pages. You leave able to build something that remembers. The path runs through PHP on your own machine, then PHP on a real host, then SQL, then a login page, then create, read, update, and delete against a live database — CRUD, which is simple to describe and unforgiving to get wrong.

The reading is The Joy of PHP, and recorded lectures cover the parts that go faster with someone talking over them.

How scoring works here

Peer-reviewed work normally splits two thirds to your submission and one third across two reviews, so a 30-point assignment is 20 + 5 + 5. Assignments marked NPR skip the review half. The full arithmetic, including how to read a total that puzzles you, is on the Grading page.

The rules your pages must satisfy

The checker tests everything you build against the Web Standards, and your whole site against the Course Site Standards. Run the checker before you submit — see Validation — and use the review checklist on your own work before anyone else sees it.
