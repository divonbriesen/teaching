CIS110 • Introduction to Computers

Catalog description

This course introduces computer concepts, including fundamental functions and operations of the computer. Topics include identification of hardware components, basic computer operations, security issues, and use of software applications.

Official description from the Combined Course Library of the North Carolina Community College System. Contact hours and prerequisites are set by each college, so check your own college's catalog for the section you are enrolled in.
