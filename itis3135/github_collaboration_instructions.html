Collaborating on GitHub (Team Activity)

Only do this if your instructor assigns a team activity. You'll build a repo for your class, invite your classmates to it, and visit theirs - so everyone has practice working in each other's repos. Finish the GitHub setup first.

Create Your Team Repo

  • Create a repo named with your course ID and your last name, e.g. itis3135-smith - lowercase, no spaces.
  • Tick the checkbox that creates a readme file. If you forget, you'll have to add one by hand.
  • In the readme, start with a simple description along the lines of: "This repo is to get comfortable collaborating with my classmates."

Invite Your Classmates

  • Find your classmates' GitHub IDs - the first link in each classmate's introduction.
  • On github.com, in your repo's settings, add each one as a collaborator.
  • In a large class, invite at least ten. A few classmates won't have posted a working link yet, so a bigger list keeps your activity from stalling.
  • List everyone you invited in your readme: 
    I've invited the following to collaborate on this repo:
- classmate-one
- classmate-two
- classmate-three

Visit Theirs

  • Each time you get an invitation to someone else's repo, accept it.
  • Open their readme and, after your name on their invite list, add a line like "Your Name was here - date and time". That shows you've connected and can edit their files.
  • Make your name a link to your GitHub profile, and add a link to your own class repo. Readmes use markdown, so: 
    [Your Name](https://github.com/yourgithubid) was here — Oct 21, 2:15 PM · [Class Repo](https://github.com/yourgithubid/itis3135-smith)

When You're Done

Every classmate has a repo for the class, and every classmate is a collaborator on every repo - so from any readme you can reach any other repo.

Getting Busy

Your own repo is for your work. It gives you practice saving (committing) your files to GitHub and getting them back. Working with a group gives you experience in version control on top of that.

If your class has a group project that uses GitHub, your instructor should invite you as a collaborator on the repo created for the course. If you haven't been invited, ask on the class discussion forum.
