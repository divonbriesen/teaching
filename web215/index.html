WEB215 • Advanced Markup and Scripting

Catalog description

This course covers the advanced programming skills required to design Internet applications and interactive web content. Emphasis is placed on the programming techniques required to develop Internet applications, interactive web content, frameworks, and using libraries.

Official description from the Combined Course Library of the North Carolina Community College System. Contact hours and prerequisites are set by each college, so check your own college's catalog for the section you are enrolled in.

Details

  • 3 credit hours
  • 2 class hours, 3 lab hours
  • Prerequisite: WEB115, at most colleges
  • North Carolina Community College System
