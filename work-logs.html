Layout Sample

Use this outline as the model for your work log so each module, time entry, location, and task list appears in a consistent format.

Work Log Template (After Starter Post)

So-and-So's Work Log - Week #Letter

Where your LMS gives the post its own subject line, that line carries this text. Where it doesn't, make it an h4 inside the post.

  • Day Date: Start Time - End Time = Total Time
  • Location of work
    • What you did
    • Something else you did
    • ... and so on
