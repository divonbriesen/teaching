Resources

Tools and references I point students at across every web course. Nothing here replaces the course material — these are the things worth having open in another tab.

Learning Platforms

  • freeCodeCamp — free certifications, and graded coursework in several of my courses
  • Codecademy — interactive courses, used for the language and framework basics
  • Khan Academy — the spine of ITSC1110, and useful for shoring up fundamentals anywhere
  • edX — university courses; Harvard's CS50 is worth your time if you want the deeper version

Development Tools

  • GitHub — version control, and GitHub Pages hosts most of what you build for me
  • VS Code — the editor I recommend, with Live Server for local previewing
  • Chrome DevTools — inspect, debug, and see why the layout did that
  • JSFiddle and CodePen — somewhere to try an idea without building a page around it

Design and Content

  • Google Fonts — where your two fonts come from
  • Coolors — build a palette you can defend rather than three colors you happened to like
  • Creative Commons — images you may legally use, with the attribution terms attached
  • Paper Leaf's quick-reference posters on the principles, elements, and color theory — print one and put it where you work

Validators

  • W3C HTML validator
  • W3C CSS validator
  • The Vicunadator and the Accumulus cloud, both explained under Validation

Reading

  • Robin Williams, The Non-Designer's Design Book — the source of CRAP, and the fastest design education available for the money
  • Jon Duckett, HTML and CSS and JavaScript and jQuery — clear, visual, and good to own even now
