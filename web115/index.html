WEB115 • Web Markup and Scripting

Catalog description

This course introduces Worldwide Web Consortium (W3C) Internet programming using JavaScript. Topics include basic syntax, object-oriented programming, functions, variables, events, arrays, validation, accessibility, and web standards.

Official description from the Combined Course Library of the North Carolina Community College System. 3 credit hours, 2 class hours and 3 lab hours.

This is not a beginner course

It assumes you have already written a fair amount of HTML and CSS and do not need help with the basics. Plenty here will still be new, so ask early and often — but if you have never built a page before, talk to me before the add period closes.

How the course runs

  • You submit a link, on a discussion board. You turn in almost every assignment as a clickable link posted to the board whose name matches the assignment. Not a file, not an attachment — a link that goes straight to the finished page.
  • Weeks run Monday to Sunday, and each module's work is due by midnight Sunday. The Schedule lists every week of the term with its number.
  • The class discussion board is the room. You must read it; posting is optional and earns extra credit. It is the first place to look when you log in, and the first place to ask.
  • Everything you build lives on your own site, hosted on GitHub Pages, and grows across the term. Each assignment adds to it rather than standing alone.

How grading works here

This course grades for mastery, not for percentage completed. An item is either done or it needs fixing — so a submission that is nearly right scores 1 point, not 90% of the points, and the feedback tells you what to fix. Fix it in a reply and the score follows.

Peer-reviewed assignments split their points between your own submission and the reviews you write for others — normally two thirds and one third, with individual assignments free to say otherwise. Assignments marked NPR — No Peer Review — skip the review half. The full arithmetic, and how to read a total that puzzles you, is on the Grading page.

A score of 1 does not mean you failed. It means something specific needs fixing and I have told you what. Read the feedback and reply with the correction.

Accounts and materials
