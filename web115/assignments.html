Every Module, Every Week

Three things repeat all term, whatever else the module holds.

  • Class Discussion — read it always, post when you've something. Posting earns extra credit.
  • Journal / Blog — one entry per module, plus a reply to a classmate. About 16 entries across the term.
  • Work Notes / Log — date, start and end time, total, where you worked, what you did.
