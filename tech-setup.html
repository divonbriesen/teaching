Tech Setup

Do this once, before your first assignment, on the computer you'll work on. It's the same in every course I teach. Two settings on this page (file extensions and hidden files) cause more confused emails than anything else, so don't skip them.

Required Software

  • A code editor: VS Code is the one I use and recommend. Add the Live Server extension so you can preview pages as you type.
  • Two browsers, at least. Chrome, because the Chrome DevTools show up in the course, and one more: Edge or Firefox. You test your pages in both. Safari tends to be problematic, so stick with Chrome, Edge, or Firefox for your primary work.
  • GitHub Desktop for repository management. You also need a GitHub account.
  • An image editor that can rotate, crop, and resize. Any free one will do. You resize images in the editor, not in your HTML.

Turn On File Extensions

Your computer hides the end of file names by default, so index.html shows up as just index. Then you can't tell index.html from index.htm or index.html.txt, and the wrong one won't work online.

  • Windows 11: open File Explorer, then View, Show, and check File name extensions.
  • Windows 10: open File Explorer, click the View tab, and check File name extensions.
  • Mac: in the Finder, open Settings (older Macs call it Preferences), click Advanced, and check Show all filename extensions.

Show Hidden Files

Some files and folders you'll need are hidden, like the .git folder, .gitignore, and .nojekyll. Turn them on so you can see them.

  • Windows 11: File Explorer, View, Show, then check Hidden items.
  • Windows 10: File Explorer, the View tab, then check Hidden items.
  • Mac: in the Finder, press Command + Shift + . (period). Press it again to hide them.

Check That It Worked

Make a file called index.html in your working folder. You should see the .html at the end of the name. If you see index.html.txt, your editor added a second extension, so rename the file and delete the .txt.
